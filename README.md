# Tetrix Homebrew tap

Homebrew formulae for Tetrix software.

## Install Tetrix Host

```sh
brew install tetrix-technologies/tap/tetrix-host
```

[Tetrix Host](https://github.com/Tetrix-Technologies/tetrix-host) runs the models behind your Tetrix apps on a machine you own.

## Formulae

| Formula | Installs |
|---------|----------|
| `tetrix-host` | The `tetrix-host` command |

The release script in the tetrix-host repository writes `Formula/tetrix-host.rb`. Do not edit the file here.
